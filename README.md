# Royal Engagement Invitation

This project is a static invitation website for Ashish and Shweta's engagement.

## Files
- `index.html` — main page for deployment
- `ashish_shweta_royal_engagement_invitation.html` — original working copy
- `image_70ba99.png` — local fallback background image
- `Laththe_Di_Chadar_3.mp3` — background music

## Deploy to GitHub Pages
1. In the repository, open **Settings > Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. The workflow deploys the site automatically whenever changes are pushed to `main`.
4. The site URL is `https://ashishkyadav.github.io/engagement-invitation-website/`.

## Local preview
Run:
```bash
python -m http.server 8000
```
Then open:
`http://localhost:8000/`
