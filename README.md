# Royal Engagement Invitation

This project is a static invitation website for Ashish and Shweta's engagement.

## Files
- `index.html` — main page for deployment
- `ashish_shweta_royal_engagement_invitation.html` — original working copy
- `image_70ba99.png` — local fallback background image
- `Laththe_Di_Chadar_3.mp3` — background music

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Push the contents of this folder to the repository root.
3. In GitHub, open the repository and go to Settings > Pages.
4. Set Source to `Deploy from a branch`.
5. Choose the `main` branch and the root folder `/`.
6. Save.
7. GitHub will provide a public URL like:
   `https://your-username.github.io/your-repository-name/`
